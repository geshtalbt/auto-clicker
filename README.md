# Auto Clicker

Красивое desktop-приложение для автоматизации кликов мышью на Windows.

## Возможности

- Настраиваемый интервал между кликами (дробные значения, например 0.1 / 1.5 сек)
- Глобальная горячая клавиша для старта/стопа (по умолчанию `F6`, работает в свёрнутом окне и в других приложениях)
- Выбор кнопки мыши: левая / правая / средняя
- Случайная вероятность выполнения клика (0–100 %)
- Большая кнопка Start/Stop на главной панели со статусом и счётчиком кликов
- Сворачивание в системный трей
- Сохранение настроек между запусками
- Современный минималистичный тёмный интерфейс

## Технологии

- Python 3
- PyQt6 — интерфейс
- pynput — управление мышью и глобальные горячие клавиши

## Установка и запуск

```bash
# Клонирование репозитория
git clone https://github.com/<ваш-юзернейм>/auto-clicker.git
cd auto-clicker

# Установка зависимостей
pip install -r requirements.txt

# Запуск из исходников
python clicker_app/main.py
```

## Сборка в .exe (Windows)

```bash
cd clicker_app
pyinstaller build.spec --noconfirm
```

Готовый `.exe` появится в папке `dist/` после сборки.

> Собирать `.exe` нужно на Windows (PyInstaller создаёт исполняемый файл для той платформы, на которой запускается). На macOS/Linux будет собран бинарный файл для соответствующей системы.

## Структура

```
clicker_app/
├── main.py      # точка входа
├── settings.py  # сохранение настроек
├── clicker.py   # логика автокликера
├── hotkey.py    # глобальные горячие клавиши
└── ui.py        # интерфейс (PyQt6)
```
